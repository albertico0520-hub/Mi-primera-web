Cómo funciona

El recorrido de una solicitud, hasta donde llega esta demo.

Estos pasos describen un proceso posible. En esta página el recorrido se detiene en el formulario: no se prepara un presupuesto ni se aparta un horario.

  1. 1

    Cuentas el espacio

    Tipo de lugar, ciudad y una preferencia de día. En la demo puedes usar datos inventados.

  2. 2

    Se revisaría el alcance

    Un equipo real pediría fotos o una breve llamada para no adivinar el trabajo.

  3. 3

    Habría una propuesta

    Precio, duración y lo que queda fuera del servicio. Aquí no se genera esa propuesta.

  4. 4

    La visita se confirmaría aparte

    Solo después de una respuesta humana y un sistema de reservas. Esta página no hace esa confirmación.
